# 后端环境、配置与验收

先复用应用已经约定的开发启动方式。需要新本地配置时，跟踪脱敏示例，真实数据源与凭据放忽略文件或环境变量；检查 ignore 后再写入，不复制当前用户 Maven 凭据或默认管理密码。

IDEA 与 spring-boot:run 的 working directory/config location 可能不同。确认真正的启动子模块、profile、配置文件路径和服务端口；聚合 POM 不一定可运行。模块跳过 Boot 打包与启动模块的配置分别核对，不在整个父 POM 无差别启用或禁用。

本地缓存、数据库和外部服务沿项目已有支持选择隔离实现。需要 Docker 时明确镜像、端口、数据卷所有权和持久性；不为提速关闭字典、迁移或模型同步的正式监听器。没有合适测试数据库就报告条件，不能自动连接线上。

验证链：构建产物中的资源/配置 → 应用启动 → loader/扫描/模型刷新 → 真实接口与数据操作 → 权限负向 → 页面交互。health=UP、端口打开、返回401和编译通过各只证明一部分。

涉及事务、约束、RPC 或通知的行为测试使用隔离实例和测试接收者。重启/失败时保留最先异常及日志位置，不删除他人进程、数据卷或生成的部署制品。平台维护的 run-tests/operate-ouroboros 只在具有对应 monorepo 脚本时使用，不要求普通消费项目安装它们。
